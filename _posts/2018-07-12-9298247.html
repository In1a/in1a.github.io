【算法】

           巴什博弈

           若有(m+1)个石子，显然先手不能直接取完，后手必胜

           因此，我们可以把石子总数表示为 ： n = k(m+1) + r

           若r不为0，则先手取走r个，若后手取s个，先手取（m + 1 - s)个，只要保证留给对手的石子数是(m+1)的倍数即可，先手必胜

           否则，先手必败

【代码】

           

#include<bits/stdc++.h>
using namespace std;

int T,n,m;

int main() 
{
        
        scanf("%d",&T);
        while (T--)
        {
                scanf("%d%d",&n,&m);
                if (n % (m + 1)) printf("first\n");
                else printf("second\n");    
        }
        
        return 0;
    
}
