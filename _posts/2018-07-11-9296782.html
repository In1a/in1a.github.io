【题目链接】

            http://codeforces.com/contest/451/problem/A

【算法】

            若n和m中的最小值是奇数，则先手胜，否则后手胜

【代码】

           

#include<bits/stdc++.h>
using namespace std;

int n,m;

int main() 
{
        
        scanf("%d%d",&n,&m);
        if (min(n,m) % 2 == 0) printf("Malvika\n");
        else printf("Akshat\n");
        
        return 0;
    
}
